### Claude Code

- 2.1.285, implicit print permissions change on third-party routes or when telemetry is off. ## Owner decisions

- Output style: not supported. Claude fixes it at session start, and it is personal configuration. Agreed with the owner on 2026-09-15.
- `--permission-prompts none`: fits only an unattended run, because Arc routes asks to the panel.
- Tracking: this ledger is the one list of vendor findings. A chosen finding becomes a plan with a row in `.claude/plans/ROADMAP.md`, and its captured sample becomes a synthetic fixture in the reader's test file. No session-start version alert. Run this skill by hand about weekly, and move to a weekly `/schedule` routine if runs lapse.
