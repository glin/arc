# Panel accessibility

Read this guide when changing keyboard movement, focus recovery, accessible names, or panel hints. [Session list](rail-and-navigation.md) owns filtering and grouping.

## Keyboard model

The session list and timeline use separate keyboard models. [Keyboard and screen-reader contract](#keyboard-and-screen-reader-contract) defines entry, movement, group structure, resizing, and focus recovery.

Disclosure buttons carry `aria-expanded`. A folded bucket remains reachable and names what it contains. Archive, pin, and the label editor are real buttons with accessible names and visible focus.

A session list card takes `l`, `p`, and `Delete` on the session it names. The key handler also takes `Backspace` on macOS, where the hint names `Backspace` alone. It refuses the key on an archived session, which is what the pin entries on both context menus also do.

Pressable controls with information beyond their visible text use the panel hint instead of a native browser title. These controls include session list actions, both setup carets, the primary New action, the session heading press, and a turn card's head. A hint gives the short action and optional key, then its effect when one exists. The session heading gives the full session name first and the full local time of the last activity second when available. Only a session that opens in another registered checkout adds a `Started in` line. The hover names that worktree as plain text. The pinned name links the worktree name and shows its complete selectable destination. The host preserves path suffixes through `vscode.Uri.file` and reveals the folder in Explorer. A removed focused worktree link leaves focus in the name popover. Escape returns focus to the heading. The default checkout and its ordinary subfolders add no line. Unknown opening identities also add no line. Its name draws at regular weight in a wider box and stops at eight lines. A closing parenthesis stays part of the name. A path breaks after each slash or backslash that has text on both sides. A turn head gives its plain press first, then its status, then what Shift+click or Shift+Enter does to every shown turn. Pointer hover opens a plain hint after a short delay, and a compact card's hover after the longer delay the Compact rows paragraph names. Moving the pointer from an open hint to another control opens that control's hint at once. Moving it onto a compact card closes any open hint, including one that keyboard focus opened, and the card waits its full delay. Keyboard focus opens either one immediately. Pointer leave, focus leave, Escape, a press, session list scrolling, resizing, or removal of the control closes it. The spoken control name still includes the session title where the action belongs to one. Read-only text and rows inside an open popover keep native titles.

The label popover keeps its own walk. It sits outside the session list and timeline navigation scopes. Arrow keys move between the box, its cross, the create row, and the checkboxes. `Home` and `End` retain caret movement inside the box and reach the popover boundaries elsewhere. The cross shows while the box holds text. Pressing it empties the box and keeps focus there. `Space` and `Enter` toggle a focused checkbox. `Enter` in the box applies an exact existing label or takes the create offer. Plain `Tab` in the box applies the first visible unapplied existing label, clears the find box, and keeps focus there. The row that `Tab` applies shows a `Tab` key before its count, and the box carries a screen-reader description of the key. `Tab` keeps its native walk when the box is empty or no unapplied existing label matches, and then no row shows the key. `Escape` shuts the popover and returns focus to the control that opened it. The native find box stays mounted and uncontrolled while rows reconcile, which preserves its caret, undo history, and active input-method composition. Only an explicit reset clears it.

## Keyboard and screen-reader contract

Every visible action is keyboard reachable and has an accessible name that includes its visible information. Controls use native elements where the layout permits. Inline Prompt box skill marks use spans with the button role so they wrap with text. Disclosure controls carry `aria-expanded` and name what they open. A pressable control that needs a tooltip uses the panel hint, while read-only text and a row inside an open popover use a native `title`.

The Timeline landmark contains labelled session sections. Each visible session title contains its name button. Turn articles and compaction sections use their card heading as the accessible name. Turn body sections use visible subheadings. A session heading wraps its buttons and never becomes a control itself.

The Sessions navigation landmark contains a heading that remains available when the visible title does not fit. Each group has a native heading and labelled list, with one list item per mounted session occurrence. Disclosure headings report total matches. Their `aria-controls` names the group list only while that list exists. Folded and empty groups omit that relation. Show more follows its group list as a separate native button. Group headings stick below the measured session list header. `#rail` remains the scroll owner.

Every session selector, sibling action, disclosure, saved-view menu, and Show more button keeps its native Tab stop. Tab and Shift+Tab cross the session list in document order. Up and Down supplement Tab by moving between disclosures, selectors, and Show more buttons. Home and End reach the first and last of those controls. Arrows from a sibling action start from its session selector. Movement never selects a session. Modified, prevented, composing, and editable-field keys retain their existing behavior.

From the first timeline stop, Shift+Tab reaches the separator, then the last session list control. Home returns to the first local navigation control without traversing rows. Repeated Shift+Tab presses move through the header controls to Search. Search narrows the list, and native Tab reaches the matching selector and its sibling actions. Enter or Space activates the focused native button.

The displayed session selector carries `aria-current="true"`, including each repeated group occurrence. Both densities retain the complete accessible name and full local activity timestamp. Figures and labels remain read-only parts of that selector. Clock updates change text without a live announcement.

Reconciliation preserves focus by session identity, group occurrence, and action. A removed occurrence returns to a surviving occurrence, then its disclosure, then a nearby selector, then a visible header control. Folding a focused group returns focus to its disclosure. Show more retains focus while rows remain undrawn. Its final press returns focus to the last newly drawn selector. Unrelated updates leave focus unchanged. Hiding the session list transfers focus from its controls or separator to visible compact navigation or the session view.

The focusable vertical separator controls the session list width. Left and Right move it by 10 CSS pixels. Home selects 160 pixels. End selects the viewport width minus the rendered separator width, floored and bounded below by 160 pixels. Its accessible range and current value use those same bounds. Keyboard changes save the width immediately. Pointer changes save on release or cancellation. A smaller viewport caps the drawn width without replacing the saved preference. Space returning restores that preference. A deliberate resize updates it.

The timeline keeps one independent roving Tab stop. The navigation owner marks matching timeline controls with `data-roving` as subtrees arrive or change classes. It caches the complete walk and its visible members until the page changes. Controls outside that scope retain ordinary Tab stops. The owner ends its injected page observer on disposal.

An open popover rebuilds only when its own content changes. A shared parent fingerprint would rebuild it for unrelated updates. Replacing a focused native control closes its option list, even when focus is restored.

Disclosure state lives outside the card element. Card repainting preserves the card's open state, Activity filter, and prompt disclosure.

Activity owns command disclosures by step identity, including when an adjacent call groups a standalone step into a run. The log restores focus after retention removes its focused row. The timeline preserves that local choice while the same card survives.

Prompt recall starts when the caret is at the text field's beginning. Both arrow keys navigate while a recalled prompt is displayed. Recall announces its position in a separate live region because changing the focused field alone produces no screen-reader announcement.

A control that only exists at some panel widths is drawn as a control at those widths and as plain text everywhere else. The session heading's label chips file the session list under one label. Below the width the session list exists at, there is no list to file, so the chips are drawn as spans. A button that answers no press still takes a stop in the reading order and does nothing when it is pressed. The roving selector names the tag rather than the class for that reason. A chip that only reads keeps a native `title`, and the same chip as a button carries the panel hint instead.

A chip on a session list card cannot become a control. The card is itself one button, and HTML forbids a button inside a button. The session heading's own menu button is a sibling of its name button for the same reason: `.sessionheading` is a flex row holding the name button, the pin, the menu button, and the layout gear, in that order. The name button holds only the title. A press, `Enter`, or `Space` on it pins the whole name open in the figure popover. It uses the `aria-pressed` state and the close rules of a pinned figure. There the name scrolls and its text can be selected. Tab on the name button enters the first popover Tab stop. Down enters its first action. Without those stops, an overflowing pinned name receives focus in the box. The arrow, Page, Home, and End keys then scroll it. Escape, a second press, or a press outside closes it, and Escape returns focus to the heading. Its panel hint gives the full session name first and the full local time of the last activity second. The pin, the menu button, and the gear sit outside it. The pin pins or unpins the session. The menu button answers its own press with the native menu. The gear opens the Timeline layout dialog. All three follow `.session` in the roving walk, in the order they are drawn. The heading draws no age, because the session list row and the newest card head draw it. An `.sr-only` span carries the full local time of the last activity, so the heading's accessible name keeps it.

The Activity head is a row. Its word controls disclosure, each message count is a filter button, and each tool-category count opens the shared raw-tool detail. These controls keep ordinary tab stops. Run and command controls share a separate roving tab stop inside the log, outside the timeline's walk.

A section head can carry a second action on a modifier key, with nothing on screen to say so. The Activity word opens or shuts the section on a plain press. A press with Shift held moves every visible message at once. The word's hint describes that second action. The panel names the hint's detail in `aria-describedby` while the word has focus. A hint can draw its title alone, and only an available detail receives that description link. A bulk press puts focus on the word.

The New session menu is a dialog of native buttons, and both of its triggers say so in `aria-haspopup`. Its list of pinned and recent setups keeps its own walk with one tab stop, outside the timeline's roving walk, like the label popover. Each list row holds an apply button, an Edit button and a pin button side by side. The stop starts on the first row's first button that can take focus, and it follows focus inside the list. Tab enters the list from the "Same setup as current" row and leaves it for the Agent field. Up and Down move to the same kind of button in the next or previous row and wrap at the ends. Home and End move to the first and last row. A row without that kind of button takes focus on its pin. Left and Right move across one row's buttons and stop at its ends. An unavailable pinned row's apply button is disabled, so the walk lands on its Edit or its pin. A refresh that disables the stop's apply button moves the stop to that row's pin. A refresh that removes the stop's row moves the stop to the same button in the next row, else the previous row. Focus never stays on a disabled button. Opening the menu focuses the "Same setup as current" row, else the list's stop, else the Agent field. Edit, and an opening that asks for a custom setup, focus the Agent field. After a pin press, focus moves to the new pinned row's pin once a refreshed list shows a new pinned setup with those values. After an unpin press, focus moves to the next row's pin once the pinned setup is gone, else to the previous row's pin. A refresh that shows neither result leaves focus on the pressed pin, or on its nearest remaining neighbor when that row is gone. Moving focus off the pressed pin before the result arrives cancels the move, so the result moves focus nowhere. Agent, Model, Effort and Permissions use the shared select-only combobox. Each field has one Tab stop, and its options never receive DOM focus. Arrow keys open the list and move its tentative selection without wrapping. Home and End reach the boundaries, and Page Up and Page Down move by ten choices. Printable keys search option names. Enter, Space, Alt+Up, Tab or leaving the field accepts the tentative choice. Tab retains normal browser focus movement. Escape or pressing the expanded trigger cancels it. Pointer hover changes only the visual treatment. Pressing an option accepts that option. Disabling the focused field moves focus to the next enabled visible control, then backward if none follows. Model and Effort mark the applied CLI defaults when known. Loading and unavailable metadata remain field statuses. The field pin keeps focus after a press, and its pressed state follows each refreshed list. A hint open on Edit or a pin takes the first Escape, and the next Escape closes the menu.

An agent request draws one question at a time, behind a real tab strip. The strip holds one tab stop of its own, and it is not part of the panel's roving walk. Its tabs, and the request's fold, sit before the request's actions in the page, so the query that moves focus to the next request after one resolves excludes both. Three polite regions stay apart: an arriving request, the move to the next question, and the sentence beside Send. A region that mixed two subjects would read as one.

Keyboard operation is part of the component contract. Mouse-only behavior does not ship. Visible focus and readable words carry meaning. Glyphs and color do not carry meaning alone.
