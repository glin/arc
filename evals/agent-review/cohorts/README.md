# Production review cohort

[review-diversity-v1.json](review-diversity-v1.json) records source identities, independent root causes, assigned-input audits, and offline qualification receipts. Its status distinguishes qualified entries from final coverage.

Check fixture behavior and exported bytes:

```powershell
node evals/agent-review/run.mjs validate
node evals/agent-review/run.mjs qualify --cohort evals/agent-review/cohorts/review-diversity-v1.json
node evals/agent-review/run.mjs check-cohort --cohort evals/agent-review/cohorts/review-diversity-v1.json
```

`qualify` checks source and reference hashes, historical blob identities, local imports, instructions, answer markers, behavior, and defect reinjection. It uses temporary development scratch and removes it after checking.

`check-cohort` runs qualification and checks final coverage targets. It exits with status 1 and lists missing counts until the complete cohort qualifies.

Prepare assigned inputs without launching a model:

```powershell
node evals/agent-review/run.mjs run --config evals/agent-review/experiments/review-diversity-phase1.json --dry-run
```

This profile permits preparation only. Paid execution requires a separate complete-cohort registration. Existing live profiles retain their execution behavior.

The opt-in `audited_instructions` manifest captures a common current-instruction subset. Original and exported hashes record retained documents and omissions. Current architecture repair guidance stays outside assigned inputs. Default instruction capture keeps its existing document manifest.

Historical source comes from recovered commits. Most supplied diffs preserve their scoped Git changes. The padded-parser case uses a reconstructed causal introduction because its recovered change leaves the parser unchanged. Its recorded base adds two production padding branches to the candidate snapshot. The same target check passes that base and fails the candidate. Its diff removes only those branches and contains no correction comments. Original submitted review prompts and review evidence are unavailable.

Candidates retain their production caller and consumer paths. Compiled runtime artifacts bundle Node dependencies and erase TypeScript types. Source files remain byte-identical to their recorded Git blobs. Provenance records controlled host stubs and test transformations.

Target checks, corrected references, provenance, instruction audit details, and scoring keys stay outside assigned inputs.

The CLI control offers `node runtime.cjs --help` in its assigned workspace. Other cases provide source review without a model-side command. Qualification uses synthetic records, controlled promises, and platform stubs. It does not establish model execution or real system-tool coverage.

The archive test copies tracked eval artifacts without Git, relocates the archive, and repeats qualification. Runtime qualification requires Node 22.18 or later. It requires no package install or historical objects.

Assigned-input audits do not deny host reads or network access. These cases support local exploratory comparisons under the runner's existing launch contract.

## Rebuild the production exports

The developer recipe reconstructs source closures, runtime bundles, target-check transformations, causal-base evidence, and the audited instruction bytes. It requires a Git clone containing the recorded source commits and existing build dependencies. It performs no install or paid request.

```powershell
node evals/agent-review/rebuild-corpus.mjs --repository <source-clone> --out <fresh-directory> --check
```

The recipe requires esbuild 0.21.5, TypeScript 5.9.3, marked 4.3.0, and diff 5.2.2. It checks regenerated bytes against frozen hashes and repeats qualification. Its instruction source is commit `ac1e28c6684c9d399bc8f8fddcf420f2dd86182a`. Later checkout documentation never replaces that snapshot. The output retains a reproduction receipt and regenerated artifacts. Its temporary build directory is removed after success or failure. Remove the requested output directory after inspecting its receipt.
